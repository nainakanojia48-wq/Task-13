# Javascript Even or Odd checker

## Project description
This project is a simple javascript programe that checks whether a number is even or odd using if-else statements.

## Features
- checks multiple number
- uses javascript if-else condition
- displays output in browser console
- beginner-friendly project

## Technologies used
- HTML
- JS (internal)

## How to run
- open the project folder
- double click on index.html
- openbrowser console
- view output
